# 🏠 Simulatore Immobiliare

Lead magnet per simulare operazioni immobiliari: acquisto, ristrutturazione, affitto e vendita.

## 🚀 Tech Stack

- **React 18** + **TypeScript** - Framework UI moderno e type-safe
- **Vite** - Build tool velocissimo
- **TailwindCSS** - Styling utility-first con colori custom (verde #22c55e, arancione #f97316)
- **react-hook-form** + **zod** - Gestione form e validazione
- **recharts** - Grafici interattivi per analisi finanziaria
- **lucide-react** - Icone moderne

## 📦 Installazione

```bash
npm install
```

## 🛠️ Sviluppo

```bash
npm run dev
```

Apri [http://localhost:5173](http://localhost:5173) nel browser.

## 🏗️ Build

```bash
npm run build
npm run preview
```

## 🚢 Deploy

Deploy automatico su **Vercel** da GitHub.

## 📁 Struttura Progetto

```
src/
├── components/    # Componenti React riutilizzabili
├── hooks/         # Custom hooks
├── utils/         # Funzioni utility
├── types/         # Type definitions TypeScript
└── data/          # Dati statici e configurazioni
```
